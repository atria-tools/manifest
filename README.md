Atria-tools
===========

Get island:
-----------

```{.sh}
pipx install island
```

Create the tree:
----------------
```{.sh}
mkdir atria_tools
cd atria_tools
island init https://github.com/atria-tools/manifest.git
island sync
cd ..
```

```{.sh}
mkdir atria_tools
cd atria_tools
island init git@github.com:atria-tools/manifest.git
island sync
cd ..
```

Now all is done ...
