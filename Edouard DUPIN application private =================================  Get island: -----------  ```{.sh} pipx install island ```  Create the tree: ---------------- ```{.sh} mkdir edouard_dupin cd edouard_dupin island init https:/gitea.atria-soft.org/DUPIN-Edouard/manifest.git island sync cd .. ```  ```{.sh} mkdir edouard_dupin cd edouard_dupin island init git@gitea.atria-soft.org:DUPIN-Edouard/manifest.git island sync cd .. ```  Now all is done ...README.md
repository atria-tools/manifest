Atria-tools
===========

Get island:
-----------

```{.sh}
pipx install island
```

Create the tree:
----------------
```{.sh}
mkdir edouard_dupin
cd edouard_dupin
island init https://gitea.atria-soft.org/atria-tools/manifest.git
island sync
cd ..
```

```{.sh}
mkdir edouard_dupin
cd edouard_dupin
island init git@gitea.atria-soft.org:atria-tools/manifest.git
island sync
cd ..
```

Now all is done ...
